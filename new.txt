### **Story Title:**  
**Select Device to Replace – Hardware Storefront Flow**

---

### **Story Description:**  
This story covers the implementation of the "Select Device to Replace" page in the Hardware Storefront flow. Users will see their current device and the device it will be replaced with. A dropdown will allow users to select the device from their existing inventory. Once selected, the device appears as a removable tag, and users can proceed by clicking “Continue.” The UI must follow the provided Figma design, and behavior should be intuitive and responsive across devices.

---

### **Acceptance Criteria:**

1. The page must display both the current device and the replacement device information (e.g., "Device: XYZ Model 123" and "Replace: XYZ Model 123").
2. A dropdown should be available for users to select a device from their existing inventory.
3. When a device is selected, it should appear as a tag with a close (X) icon to remove the selection.
4. The "Continue" button must be disabled by default and only enabled once a device is selected.
5. The "Go Back" button must return the user to the previous screen without saving selections.
6. The layout, styles, spacing, and elements must exactly match the Figma design specifications.

Here’s a complete **User Story** for the **Peripherals Selection Page** based on your image:

---

### **Story Title:**  
**Select Peripherals – Hardware Storefront Flow**

---

### **Story Description:**  
This story focuses on the implementation of the “Select Peripherals” page in the Hardware Storefront flow. After selecting the main device to replace, users are shown a set of optional peripheral accessories (e.g., headsets, keyboards, mouse) that they can add to the replacement request. The user can select one or more peripherals by clicking an “+ Add” button under each item. The layout is card-based, visually presenting each peripheral with an image, brand name, and short description. The UI must adhere to the Figma design guidelines and support multi-selection.

---

### **Acceptance Criteria:**

1. The page must display the main and replacement device info at the top (e.g., “Device: XYZ Model 123” and “Replace: XYZ Model 123”).
2. Peripherals should be listed in a grid of cards with image, brand name, model, and a short description.
3. Each card must include an **“+ Add”** button that allows users to select that peripheral.
4. Once selected, the button should toggle to **“Added”** or visually indicate that it’s selected.
5. Users can select multiple peripherals, and the state must be retained as they navigate.
6. “Go Back” should return to the previous page, and “Continue” should take the user to the next step while storing selections.
