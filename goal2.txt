## **SMART Goal 1: ML-Based Auto-Approval for Storefront Requests (Q3)**

The goal is to implement machine learning–based automation to streamline the device and peripheral approval process in the Storefront platform. This solution will intelligently auto-approve requests where the device is nearing end-of-life (within 90 days), the user is a manager or above, or the request is for a first-time peripheral. These use cases are low-risk and highly repetitive, making them ideal for intelligent automation.

The project aims to reduce manual approval volume by 50% and decrease the overall request fulfillment time by 30%. Approval decisions will be logged for audit and compliance. The solution will leverage historical request data, Microsoft Graph role attributes, and basic predictive modeling or a rules engine to make real-time decisions at the point of request submission.

This automation directly addresses provisioning delays caused by manual workflows and helps IT focus on more complex approvals. It enhances efficiency while maintaining transparency and control. The system will be fully implemented and rolled out by the beginning of Q3 2025, with performance reviewed by the end of the same quarter.

## **SMART Goal 2: Smart Triage Workflow with VDI Suggestions (Q4)**

The goal is to design and implement a smart triage feature in the Storefront platform that captures user intent at the beginning of the request process. Instead of defaulting to physical laptop provisioning, the system will ask why the device is needed (e.g., onboarding, testing, temporary access). Based on the response, the system may recommend a virtual desktop (e.g., VDI or cloud VM) as a faster and more cost-effective alternative.

This feature will aim to reduce physical device requests by 15% for short-term or temporary use cases, while improving provisioning speed for contractors and project-based users. The logic will be built using existing Storefront and Microsoft Graph data, with integration into available VDI platforms like Azure Virtual Desktop or VMware if applicable. It will also track user selections and virtual-to-physical conversion rates for future optimization.

Smart triage helps reduce unnecessary hardware provisioning, cuts costs, and supports sustainable IT operations. It adds a layer of intelligence that aligns provisioning with actual user needs. This feature will be developed and fully delivered by the end of Q4 2025, with impact monitoring continuing into early Q1 2026.

SMART Goal 1: Complete Machine Learning Training Focused on Workflow Automation (Q2)
The goal is to complete a structured training program in machine learning with a focus on real-world applications in workflow automation. This training will cover key concepts such as supervised learning, classification models, decision trees, and model evaluation — with an emphasis on applying these techniques to internal approval systems like Storefront. The training will also explore how to prepare datasets, define relevant features, and measure the accuracy and fairness of predictive models.

The objective is to build a foundational understanding of how ML can be responsibly used to automate business logic, reduce manual intervention, and improve decision-making. This training will be completed by the end of Q2 2025, and a summary of key takeaways will be documented and shared with the team. This will ensure readiness to lead the next phase of implementation with confidence and technical clarity.
