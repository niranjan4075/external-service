## **SMART Goal 1: ML-Based Auto-Approval for Storefront Requests (Q3)**

**Goal:**  
Implement intelligent automation using machine learning to streamline the hardware and peripheral approval process in Storefront.

### **Specific:**
- Introduce auto-approval for:
  - Devices nearing end-of-life within 90 days
  - First-time peripheral requests
  - Users with managerial or higher roles
- Rules and model will run during request submission and skip manual review where low-risk

### **Measurable:**
- Target a **50% reduction in manual approval volume**
- Reduce device request fulfillment time by **30%**
- Track approval outcomes with audit logging for compliance

### **Achievable:**
- Leverage existing request history and Microsoft Graph role data to train a lightweight model
- Integrate the model or rules engine with the backend API before request status is determined
- Work in parallel with current manual approval process for smooth rollout

### **Relevant:**
- Directly addresses delays in device provisioning due to manual manager workflows
- Reduces repetitive approvals, especially for predictable patterns
- Empowers IT teams to focus on complex cases instead of routine ones

### **Time-Bound:**
- Complete implementation and pilot rollout by **start of Q3 2025 (July 1)**
- Conduct post-implementation impact review by **end of Q3 2025**

## **SMART Goal 2: Smart Triage Workflow with VDI Suggestions (Q4)**

**Goal:**  
Design and launch a smart triage mechanism to understand user intent and suggest VDI/VM solutions when suitable, reducing unnecessary physical hardware requests.

### **Specific:**
- Add a “Why do you need a device?” prompt on the request form
- Based on selection, show suggestions such as cloud VM, short-term virtual access, etc.
- Use this to divert eligible cases from physical provisioning to faster digital alternatives

### **Measurable:**
- Aim for **15% reduction in physical device requests** for short-term or temporary use cases
- Track user selections and conversion rate to virtual options
- Monitor provisioning turnaround time improvements for contractors and short-term users

### **Achievable:**
- Use Microsoft Graph data and device history to contextualize user types (e.g., contractor, temp)
- Integrate with existing Azure Virtual Desktop / VMware infrastructure if available
- Keep fallback to physical hardware if virtual is not accepted or applicable

### **Relevant:**
- Promotes sustainable hardware usage and reduces procurement load
- Enhances speed of access for users who don’t need full physical setups
- Supports cost-saving and operational efficiency goals across IT and procurement

### **Time-Bound:**
- Deliver smart triage logic and UI flow by **end of Q4 2025 (December 31)**
- Track and report results in first 30 days of rollout (early Q1 2026)
