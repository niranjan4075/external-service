### Description

Update the Storefront group tag assignment logic to support a fallback based on job title. Today, group tags are derived from the user’s existing group value in the inventory table, but this is sometimes null or missing. Using the job-title mappings provided by Curt and Diego, introduce a new lookup table so that when the primary group tag is not available, Storefront assigns the appropriate group tag based on the user’s job title.

---

### Acceptance Criteria

* When a valid group tag exists in the inventory table, it continues to be used as the primary source.
* If the inventory group tag is null or missing, the system looks up the user’s job title in the new mapping table and assigns the corresponding group tag.
* A default/“no match” behavior is defined for job titles that are not present in the mapping table.
* Logic is implemented in a single, reusable component/service and covered with unit tests for both primary and fallback scenarios.
* Sample test users are validated end-to-end to confirm correct group tag assignment from inventory first and job-title mapping as fallback.
