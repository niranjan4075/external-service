### **Description**

Implement an ELT & Executive workflow within Storefront that allows executives and ELT-level users to request any device or accessory without requiring manager approval. When an executive submits a request, the system should automatically create a work order and route it directly to Mobility Ops for fulfillment. Role detection should be based on AD groups or designated executive identifiers.

---

### **Acceptance Criteria**

* Executives/ELT users are identified through a specific AD group or role configuration.
* When an executive submits a request, the workflow bypasses all manager approvals.
* A work order is automatically created and routed to Mobility Ops for fulfillment.
* UI and API flows clearly reflect that the request does not require approval for executive users.
* Testing verifies that non-executive users still follow the standard approval workflow.

---

### **Benefit Explanation**

This workflow streamlines device acquisition for executives by eliminating unnecessary approval steps and ensuring faster fulfillment. It reduces processing time, improves executive experience, and maintains clear operational routing through automated work order creation.
