### **Question 3 – Overview:**

This implementation introduces a role-based storefront application that integrates with Slack and Remedy to automate the end-to-end device request and approval workflow.

When a user logs into the storefront, they see a curated list of eligible devices based on their role and department. Upon submitting a device request, the system triggers a Slack bot notification to the user's manager using Slack APIs. The notification includes **Approve** and **Reject** buttons to capture decisions in real time.

Once a decision is made:
- The response is logged and stored within the system’s database.
- An automated work order is created in **Remedy**, GEICO's internal IT Service Management platform, using system APIs for downstream processing, auditing, and fulfillment.

This integration significantly reduces manual intervention, eliminates delays in manager approvals, and ensures that device provisioning is secure, trackable, and compliant with enterprise standards. It connects Slack (for real-time decision capture) with Remedy (for ticketing and lifecycle management), enhancing overall operational efficiency and transparency.
